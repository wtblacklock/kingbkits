An invitation for a tasting night has one job an ordinary party invite doesn't: it has to set expectations before anyone shows up, so nobody arrives expecting to shotgun a beer at a wine-tasting-shaped event.

## What to actually put on it

- **Name the format in one line.** "Tasting night" or "pairing night" does more work than "party." It tells people this isn't a rager, and it tells them to eat beforehand.
- **State the tier, if you're picking one.** "Casual tier" or just the price range sets spending expectations for anyone who's contributing a bottle.
- **Give a real start and end time.** Tastings run long if you let them; a stated end time is a kindness, not a formality.
- **Say what to bring, if anything.** Most of our kits are built so the host buys everything at one tier. If you want a bring-your-own round layered in, say so on the invite, not at the door.
- **Skip the dress code unless it matters.** "Sharp casual" or nothing at all. Overdressing a living-room tasting kills the vibe faster than underdressing it.

## Timing your send

Two weeks out is the sweet spot for a tasting night: enough time for a guest to actually buy the bottle you asked for if you're running a bring-your-own round, not so far out that it falls off everyone's radar. For a bigger or seasonal night (a Halloween candy bowl tasting, an advent calendar kickoff), push that to three weeks so it survives the busier calendar around it.
